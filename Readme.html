墨语 X (InkVerse X) 用户手册

架构版本: v0.1.0 | 适配 AutoCAD 2007 ~ 2027 各版本

墨语 X 架构设计

墨语 X (InkVerse X) 是一款面向工程、建筑与测量 CAD 绘图设计的实用增强插件套件。采用了 C# 原生模块 + VLX 扩展插件库 的双引擎架构，兼顾界面交互与绘图效率。

  • C# 核心模块：提供截图、插件控制台、出图管理、图层隔离、表格交互与图纸清理。
  • VLX 扩展插件：包含坐标高程标注、智能编号、长度统计、正则文本替换、图元转换与矩阵重构。
  • 共享运行资产：采用 Shared 共享组件技术，降低磁盘占用并便于统一部署。
  • 统一界面风格：统一主题色与控件样式，兼容 WPF 与 WinForms 界面。

2. C# 核心套件使用说明

2.1 墨语 Snap (InkSnap / CSNAP 捕捉截图)

适用于 2D 工程图纸与 3D 视口的高清矢量捕捉、区域裁切与图像导出工具。提供透明背景生成与剪贴板极速交互。

CSNAP / INKSNAP 唤起截图主界面
详细操作步骤与功能说明：
  1. 唤起截图：在 AutoCAD 命令行输入 `CSNAP` 或 `INKSNAP` 并回车；或点击 Ribbon 菜单上的【📸 捕捉截图】按钮。
  2. 选择截图模式：
    • 窗口框选模式：在 CAD 视口中鼠标左键拉框，选择需要捕获的图形范围。
    • 多段线裁切模式：在图面上点击任意闭合多段线 (Polyline)，程序将自动提取该多段线的几何外框并进行异形裁切。
  3. 参数调节与预览：
    • 透明背景 (Alpha)：勾选此项可去除 CAD 背景底色，生成纯净透明背景图像（适用于插入 Word/PPT 文档）。
    • 3D 矢量渲染管线：自动提取三维视口中的实体边缘轮廓线，保持高清晰度不模糊。
    • DPI 倍率放大：支持 1x、2x、4x 超采样率设置，满足高分辨率打印排版需求。
  4. 导出与剪贴板交互：
    • 点击【复制到剪贴板】：瞬间将高质量图像放入系统剪贴板，可直接 `Ctrl+V` 粘贴至 Word、Excel、PPT 或聊天软件中。
    • 点击【导出文件】：选择保存为 PNG (透明通道)、JPG 或 BMP 文件。

2.2 Lisp 插件集中管控台 (InkLispManager)

面向 VLX 与 AutoLISP 插件脚本的集中式管理、热重载与安全调测控制台。无需记忆复杂命令，即可实现所有扩展插件的可视化管控与一键调度。

INKLISPMANAGER 呼出 Lisp 管理控制台
详细操作步骤与功能说明：
  1. 唤起控制台：
    • 在 AutoCAD 命令行输入 `INKLISPMANAGER` 并回车；或点击 Ribbon 菜单“墨语 X”选项卡中的【🧩 插件控制台】按钮。
  2. 插件浏览与检索：
    • 左侧插件列表：自动扫描展示安装目录下 `Shared\VLX` 中的所有 `.vlx` 与 `.lsp` 插件，列表直观显示插件名称、版本号与当前加载状态。
    • 自动扫码登记：若您手动向 `Shared\VLX` 目录放入了新的插件文件，控制台启动时将自动识别文件头并补全配置登记。
  3. 查看详情与直接触发命令：
    • 在左侧列表中点击任意插件（如 `ZBBZ 坐标高程系统`），右侧面板将显示该插件的图标、完整说明及支持的所有快捷命令（如 `ZBBZ`、`PLBZ`、`SCTB`、`ZBSZ`）。
    • 一键运行指令：无需在 CAD 命令行手动打字，直接点击命令卡片右侧的【▶ 运行】按钮，控制台会自动隐藏并直接在 CAD 当前视口中触发该命令。
  4. 动态热加载与强制重载 (Hot-Reload)：
    • 在二次开发或修改 VLX/LISP 源码后，无需重启 AutoCAD。
    • 在控制台中选中该插件，点击【🔄 强制重载】按钮，程序将瞬间清理旧内存镜像并重新加载最新脚本文件。
  5. 添加自定义外部插件：
    • 点击界面下方的【➕ 添加外部插件】按钮，选择电脑任意位置的 `.vlx` 或 `.lsp` 文件。
    • 控制台会自动将其安全复制至 `Shared\VLX` 共享目录，并自动生成基础描述元数据。
  6. 启动加载开关与卸载：
    • 勾选框控制：取消勾选插件名称左侧的复选框，可禁止该插件在 AutoCAD 启动时自动加载。
    • 一键卸载：选中不需要的插件，点击【🗑️ 卸载插件】，程序将解除注册表挂载并清除相关函数映射。
  7. 沙盒安全防护机制：
    • 控制台内置 `vl-catch-all-apply` 异常拦截沙盒。当某个第三方 LISP 脚本发生语法错误或中断时，控制台会自动捕获异常并恢复系统的全局环境变量（如 `OSMODE` 对象捕捉、`CMDECHO` 命令行回显），防止 CAD 环境被污染。

2.3 出图管理与智能图框 (InkBox / InkFrame)

自动识别图纸空间与模型空间内的标准图框，支持打印页面排序、比例自适应与多页 PDF 批量导出。

INKBOX / INKFRAME 呼出出图管理主窗口
详细操作步骤与功能说明：
  1. 唤起控制界面：命令行输入 `INKBOX` 或 `INKFRAME`，打开智能出图管理窗口。
  2. 图框自动搜索与识别：
    • 点击【🔍 识别图框】，系统会自动检索模型空间及所有布局空间内的图框边界。
    • 支持标准 ISO 图框 (A0, A1, A2, A3, A4) 以及自定义图块/非标多段线图框的智能判定。
  3. 图纸列表管理与视口定位：
    • 列表清晰展示每张图纸的索引序号、图纸名称、图幅尺寸 (A0-A4)、打印比例与横纵方向。
    • 单击列表中的任意图纸，CAD 后台视口将自动居中并闪烁高亮该图框，方便核对细节。
  4. 打印顺序与命名规则设置：
    • 页面排序：支持按“从左到右/从上到下”、“从上到下/从左到右”或“拾取选择顺序”进行重新编号。
    • 智能命名：可设置提取图框属性中的“图号”、“图纸名称”作为输出 PDF 文件的名称。
  5. 批量发布与 PDF 导出：
    • 选择打印驱动（如 `DWG To PDF.pc3` 或 `Microsoft Print to PDF`）。
    • 勾选【合并为单份多页 PDF】或【生成独立 PDF 文件】。
    • 点击【▶ 开始批量出图】，系统将在后台静默完成多页打印渲染。

2.4 图层忍者 (InkLayer)

快速关闭、隔离与还原图层视口干扰的辅助工具。适合复杂大图纸制图时的图层快速梳理。

INKLAYER / INKLAYERHIDE / INKLAYERISO 图层忍者工具指令
详细操作步骤与功能说明：
  1. 单击隐藏实体图层 (`INKLAYERHIDE`)：
    • 输入 `INKLAYER` 或 `INKLAYERHIDE`。在图面上鼠标左键直接点击任意实体，该实体所在的图层将立刻关闭隐藏。
    • 支持连续点击拾取多个实体图层，按 `Esc` 或回车结束。
  2. 图层隔离 (`INKLAYERISO`)：
    • 输入 `INKLAYERISO`，框选需要保留的工作实体。
    • 程序会自动将未选中的其他所有图层进行锁定或关闭，仅留选中的图层便于专注绘图。
  3. 一键无损图层还原 (`INKLAYERUNISO`)：
    • 完成操作后，输入 `INKLAYERUNISO` 或点击 Ribbon 上的【图层还原】按钮。
    • 之前被临时隐藏或隔离的图层状态将无损恢复至初始状态。

2.5 实时表 (InkTable)

AutoCAD 原生 Table 对象的高效提取与数据导出工具，支持导出为 Excel 或 CSV 数据表格。

INKTABLE / INKTABLEEXP 呼出实时表主界面
详细操作步骤与功能说明：
  1. 拾取表格：输入 `INKTABLE`，在 CAD 图纸视口中点击选择需要提取的 AutoCAD 原生表格 (Table) 对象。
  2. 解析与预览：实时表解析器会自动提取表格中的表头、单元格数值、合并单元格逻辑与行列样式，并在交互界面中生成数据预检表格。
  3. 导出为 Excel / CSV：点击【导出到 Excel】，选择保存路径，系统会自动生成标准 `.xlsx` 或 `.csv` 电子表格文件。

2.6 智能深度清理 (InkClean / InkPurge)

解决图纸臃肿、卡顿与文件体积过大的全量清理利器，可彻底清除残留 DGN 复杂线型与空图元。

INKPURGE / INKCLEAN 执行全量深度图纸清理
详细操作步骤与功能说明：
  1. 启动清理向导：在命令行输入 `INKPURGE` 或 `INKCLEAN`。
  2. 配置清理选项：
    • DGN 垃圾线型与数据：清理从 MicroStation / DGN 导入产生的庞大冗余 `DGNCOMPLEX` 线型数据。
    • 未引用图块 (Block Definitions)：清理图纸字典中未被放置使用的孤立图块定义。
    • 零长度图形实体：清除图面上肉眼无法选中、长度为 0 的孤立直线、圆弧与点。
    • 空白文本与图层：清除内容为空白字符的文字对象，以及未包含实体的废弃图层。
  3. 执行深度清理：点击【开始深度清理】，程序将在后台安全静默处理，并在命令行输出释放的文件空间统计数据。

2.7 关于面板 (InkAbout / InkMoreWorks)

查看插件系统版本号、加载状态与作品支持。

INKABOUT / INKMOREWORKS 打开关于面板 / 跳转作品页面
详细操作说明：
  1. 在命令行输入 `INKABOUT` 打开关于面板，可查看当前安装的 InkVerse X 版本信息与运行时框架（.NET 3.5 ~ .NET 10）。
  2. 输入 `INKMOREWORKS` 可直接在浏览器中打开作品展示与更新说明页面。

3. VLX 扩展插件库使用说明

3.1 ZBBZ - 坐标高程综合标注系统 (v0.1)

轻量、高效的坐标与高程综合标注插件。支持单点动态拖拽标注、图元批量自动排版标注以及一键提取坐标成果表。

ZBBZ / PLBZ / SCTB / ZBSZ 坐标标注系列命令集
详细操作步骤与功能说明：
  1. ZBBZ - 单点动态拖拽标注：
    • 命令行输入 `ZBBZ`。鼠标在视口中移动时，坐标数值与引线实时动态跟随预览。点击确定标注位置。
    • 执行过程中可按快捷键 `S` 进入参数设置，或按 `Q` 快速切换至批量标注模式。
  2. PLBZ - 批量自动标注 (带智能避让)：
    • 命令行输入 `PLBZ`，框选多段线节点、点 (Point)、圆心或图块插入点。
    • 程序会自动计算空间拓扑关系，开启 8 向文字智能避让算法，防止文字重叠并一键批量生成坐标标注。
  3. SCTB - 提取生成成果表与导出：
    • 命令行输入 `SCTB`，框选图纸中已生成的标注。
    • 根据提示输入 `Y` 指定插入点生成 CAD 原生 Table 成果表，或选择直接导出为 Excel (CSV) 数据文件。
  4. ZBSZ - 全局参数设置面板：
    • 命令行输入 `ZBSZ`，呼出参数控制台。
    • 标注格式：支持切换 `X, Y, Z` / `N, E, H` / `北, 东, 高` 等前缀。
    • 坐标系支持：支持世界坐标系 (WCS)、当前用户坐标系 (UCS) 或拾取自定义基点与旋转角度。

3.2 BHSX - 智能编号速写系统 (v0.1.1)

支持单点动态拖拽编号、图元批量智能排版编号，以及自动提取图内编号生成坐标成果表。

BHSX / BHTB 智能编号系列命令集
详细操作步骤与功能说明：
  1. BHSX - 智能编号主命令：
    • 命令行输入 `BHSX`，呼出配置控制面板。
    • 前后缀与递增初值：可自由设置编号前缀/后缀，起始初值支持数字 (如 `1`) 或英文字母 (如 `A` / `a`)，支持递增步长设置。
    • 样式定制：边框外观支持无边框、圆、椭圆、矩形；引线支持无引线、箭头、斜线等样式。
  2. 强大的 5 种自动排序引擎：
    • 批量排版模式下，支持 5 种排序规则：①按最短路径遍历、②从上到下/从左到右、③从左到右/从上到下、④拾取原始顺序、⑤沿选定多段线曲线顺延。
  3. BHTB - 编号提取生成成果表：
    • 命令行输入 `BHTB` 框选图纸中的编号块，程序会自动去重排序，并在图中生成包含“点号(编号)、X坐标、Y坐标”的成果表格。

3.3 ZCD - 长度统计标注工具 (v0.1.1)

专为工程制图研发的自动化长度统计与分项标注工具。内置无缝单位换算与 $O(1)$ 算法。

ZCD 呼出长度统计控制面板
详细操作步骤与功能说明：
  1. 设置比例与单位换算：
    • 命令行输入 `ZCD`。在面板中设置“图纸原生单位”(mm/m) 与“目标输出单位”(mm/cm/dm/m/km)，程序会自动计算比例换算系数。
  2. 17 种几何图元极速框选：
    • 点击【开始标注】，框选直线、多段线、三维多段线、样条曲线、圆弧、椭圆或多线 (MLINE)。采用头部插入算法，上万线条瞬间解析完成。
  3. 分项 S 引线与表达合成：
    • 在各线条中心自动生成分项序号 (如 ①②③)，并在鼠标指定的总标注位置生成合成长表达（如 `① + ② + 比例换算 = 128.5 m`）。
  4. 原生表格高亮生成：
    • 命令行提示 `是否在图中直接插入统计表格？[是(Y)/否(N)]`。输入 `Y` 指定点，瞬间插入带表头高亮与列宽自适应的 CAD 原生 Table 对象。

3.4 CZTH - 多行业通用全能替换系统 (v0.1)

全能文本替换与智能改写插件，集成普通通配符匹配与测绘高级数值运算双引擎。

CZTH / CZTH-RESET 主向导 / 重置规则
详细操作步骤与功能说明：
  1. 启动与扫场：命令行输入 `CZTH`。可选择全图扫描或局部框选图元。
  2. 双引擎替换规则：
    • 普通模式：支持标准通配符 (`*`, `?`, `#`, `@`)，支持全字匹配与大小写敏感。
    • 测绘高级数值模式：输入 `=12.5` 强制覆盖；`±0.05` 叠加对称公差；`0.01~0.05` 区间浮动；`++0.5` 线性顺延递增；`+0.1` / `*1.1` 数学运算。
  3. 空间几何排序与 3D 高程联动：
    • 支持按 Y(上到下)、X(左到右) 或沿选定曲线方向顺序改写。修改块属性文本时可同步更新母块的 Z 高程坐标。
  4. 对比预览与日志导出：
    • 扫场后在列表中展示修改前/修改后对比效果，点击条目可在背景视口居中高亮。执行完毕可导出为详细的对比文本日志。
  5. CZTH-RESET - 重置缓存：命令行输入 `CZTH-RESET` 一键恢复默认规则。

3.5 XZH - 全能线转换系统 (v0.1)

高效图元清洗与转换插件，支持对 17 种不同类型图元自动路由、清理并转换为统一几何对象。

XZH 启动转换控制面板
详细操作步骤与功能说明：
  1. 选择图元 (支持预选)：
    • 在图面上先框选目标图元再输入 `XZH`，或先输入 `XZH` 再框选。支持直线、圆弧、样条曲线、螺旋线、多线 (MLINE)、射线/构造线截断等 17 种图元。
  2. 查看几何统计：DCL 面板会自动按图层与图元类型分类统计数量，并动态计算选中对象的总长度与总面积。
  3. 选择目标输出格式：
    • LWPolyline (轻量多段线) [推荐]：将打散/清理后的图元无缝拼接为连续多段线。
    • Region (闭合面域)：自动校验闭合并转换为面域，适用于布尔运算。
    • Group (图元编组)：打散清理并打包编组，保留各自独立属性。
  4. 执行转换：点击【确定】，系统自动完成几何路由连接与打散清理。

3.6 XZX - 泛型图元转换矩阵 (v0.1)

图元批量转换与参数化重构系统。支持标准形状生成、自适应包围盒与闭合特征诊断偏移。

XZX 执行转换矩阵主命令
详细操作步骤与功能说明：
  1. 拾取与全图同类提取：
    • 命令行输入 `XZX`。可常规框选，或勾选“开启同类提取”（点击单图元即可自动提取全图同图层、同类型的所有图元）。
  2. 模式选择与参数配置：
    • 生成形状模式：下拉选择目标几何体（圆、矩形、外接包围盒、正多边形、五角星、心形、跑道框），输入长宽/半径及旋转角度。
    • 批量偏移模式：指定偏移距离，并设置向外/正向或向内/负向偏移方向。
  3. 闭合诊断与安全阻断策略：
    • 点击【图元统计】可查看选区图元句柄、图层与 DXF 闭合状态，双击列表条目可在背景视口中居中高亮该图形。
    • 若选中包含未首尾相连的发散图元，将触发安全策略提示框，可选择：①全部转换、②忽略发散（仅转闭合图形）、③仅转未闭合图形。
  4. 渲染输出与合并：勾选【合并并封闭目标】可将阵列结果自动融合成闭合多段线，输出至 `new_图形转换_Layer` 图层。

5. 常见问题解答 (FAQ)

Q1: 在旧版本 AutoCAD (如 2008 / 2012) 中，启动后命令行提示“未知命令”怎么办？
A: 墨语 X 在安装时会自动将插件注册到 AutoCAD 的注册表中。如果由于系统权限或绿色版 CAD 导致未自动加载，请在 CAD 命令行输入 `NETLOAD` 命令，浏览并选择您所用 AutoCAD 版本对应的子目录中的 `Framework\Framework.dll`（例如 AutoCAD 2008 选择 `{安装目录}\R17\Framework\Framework.dll`，AutoCAD 2022 选择 `{安装目录}\R24\Framework\Framework.dll`）手动加载一次即可。
Q2: 为什么提示“找不到 pdfium.dll”或 PDF 截图失败？
A: 墨语 X 采用了共享资产库设计，`pdfium.dll` 位于安装目录下的 `Shared\x86` 或 `Shared\x64` 文件夹中。请确认是否手动移动或删除过插件文件夹。若移动过，请重新运行安装程序或恢复 `Shared` 文件夹的相对位置。
Q3: 频繁弹出“安全警告：未签名的高级可信路径”如何解决？
A: 安装程序在安装时会自动将 `{安装目录}\Shared\...` 添加到 CAD 的受信任路径中。若仍弹出警告，可手动打开 AutoCAD“选项 (`OP`) -> 文件 -> 受信任的位置”，添加安装目录根路径并点击应用。
Q4: 经典工具栏没有显示图标，或者图标变成了一个问号？
A: 工具栏图标文件位于 `{安装目录}\Shared\Resources` 中。请打开 AutoCAD“选项 (`OP`) -> 文件 -> 支持文件搜索路径”，检查并确认是否已包含该 `Resources` 路径。
Q5: VLX 插件无法加载或提示 `plugins.json` 错误？
A: 可在命令行输入 `INKLISPMANAGER` 打开控制台，点击【强制重载】。程序会自动重新扫描 `Shared\VLX` 目录下的所有插件文件并更新配置文件。
Q6: 在 3D 视角或 UCS 自定义坐标系下，标注或编号位置错乱怎么办？
A: 使用 `ZBBZ` 或 `BHSX` 时，如果位于三维视图中，可以在命令控制面板中将坐标系选项切回 `WCS (世界坐标系)`，或输入 `PLAN` 命令将视图重置为二维平面。
Q7: 卸载墨语 X 时，图纸中已生成的标注和图框会丢失吗？
A: 不会。墨语 X 生成的所有图框、表格与坐标标注均基于 AutoCAD 原生图块 (Block)、多段线 (Polyline) 与表格 (Table) 对象构建，即使卸载插件，图纸文件依然保持完整且可以在没有任何插件的电脑上正常查看与打印。
Q8: 如何彻底卸载墨语 X 并清除配置？
A: 在 Windows 控制面板或开始菜单点击“卸载 墨语 X”。卸载过程中会询问是否删除配置文件，选择“是”将自动从 AutoCAD 注册表与搜索路径中清理挂载节点。

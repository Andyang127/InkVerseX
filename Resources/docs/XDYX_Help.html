SECTION 01 // OVERVIEW & INSTALLATION

系统概述与加载指南

文件名：XDYX_修订云线_v 0.1.0.lsp
纯几何原生构建
跨版本零命令差异

摒弃受 CAD 版本制约的 _.REVCLOUD 与 _.GROUP 宏命令，直接通过 entmakex 构造凸度多段线与 ACAD_GROUP 词典匿名组，在 AutoCAD 2007–2027 中表现完全一致。

AcDbRegion 布尔运算
多区域智能并集云线

支持连续框选多个矩形或多边形区域：相交重叠区域自动执行 acUnion 布尔合并为单个异形云线；互不相连的区域自动分别引出引线汇聚至同一批注文字。

XDYX_SYS 扩展数据
全图批注一键导出汇总表

每处云线批注自动写入包含【批注人、日期、修改意见】的扩展数据（XData），通过 XRA 命令即可在图纸中一键生成规范的原生 CAD 校审记录汇总表格。

三步快速加载流程

STEP 01 命令: APPLOAD

加载 LISP 程序文件

在 AutoCAD 命令行输入 APPLOAD（或直接将 .lsp 文件拖拽至绘图区空白处），点击【加载(L)】。如需每次启动自动加载，请点击右下角公文包图标加入【启动组】。

STEP 02 命令: XDYX 或 XRC

唤出批注控制主面板

输入 XDYX 或简写别名 XRC 回车，打开修订云线设置对话框。配置批注人、常用词条、云线形态及弧长后，点击【确定】或直接双击词条列表开始绘制。

STEP 03 快捷键: S 键切换

静默连续批注与面板重开

若勾选了“下次跳过此面板”，执行 XRC 时将直接进入十字光标选点绘制状态；在命令行提示指定起点时输入 S 回车即可随时重新打开设置界面。

图解 1：逆时针旋向修正与引线左右自适应对齐

Bulge = +0.520567

• 上下分层批注与修订正三角 (△) 符号：彻底重构旧版单行多行文字换行缺陷。批注正文严格居于托底基线上方（左下 BL / 右下 BR 对齐），日期信息严格居于基线下方（左上 TL / 右上 TR 对齐），水平基线居中隔离贯穿，绝不发生基线穿刺文字或转义丢失成“P时间”的异常；引线折角端点自动生成正三角形及居中修订编号。

• 凸弧恒朝外（有向面积校验）：无论顺时针还是逆时针框选，xdyx-signed-area 均自动规范顶点序列为逆时针 (CCW)，确保 DXF 42 = ±0.520567 弧向恒正外凸。

• 美工刀书法收锋笔触：手绘笔触下圆弧起点线宽 0.0、终点线宽为弦长之比例，呈现自然刚劲的工程校审书法笔意。

SECTION 04 // SEVEN SPECIALIZED WORKFLOW TOOLS

七大快捷命令图解指南

除主命令 XDYX / HH 外，系统提供了 7 个极速快捷工具，既可在主配置面板右下角快捷箱一键启动，也可直接在 AutoCAD 命令行输入对应快捷命令独立运行。

ZRC

已有对象转云线

支持批量框选

适用对象：多段线（LWPOLYLINE/POLYLINE）、圆（CIRCLE）、椭圆（ELLIPSE）、圆弧（ARC）、样条曲线（SPLINE）。

操作方式：输入 ZRC → 框选任意数量几何曲线回车，系统自动按当前弧长与笔触采样并替换为闭合云线。

DRC

独立裸画云线 (默认手绘)

默认自由手绘 F

适用场景：无需引线与批注文字的独立云线圈定。生成对象自动挂载标准 XData，支持后续使用 CRC 补连引线或 XRA 汇总台账。

核心操作：输入 DRC → 默认自由手绘(F)，在图中随意拖动光标，实时动态成弧，靠近起点瞬间自动吸附闭合并完成绘制！

全能分支：命令行输入分支关键字随时切换：R(两点矩形)、P(连续多边形带U撤销)、C(圆心半径/2P圆)、O(就地转闭合对象)、V(反转内凹/外凸弧向)、A(动态调弧长)。

GRC

文字批量刷云线框

包围盒自适应偏移

适用场景：为图中已有的单行文字（TEXT）或多行文字（MTEXT）快速套上外围修订云线框。

操作方式：输入 GRC → 框选一个或多个文字对象，系统自动计算 BoundingBox 并外扩 0.8×字高 边距生成云线。

CRC

多云线关联连引线

多对一汇聚成组

适用场景：图纸中多处相同问题已画出独立云线，需将它们全部引线指向同一处批注文字并挂载相同的 XData 属性。

操作方式：输入 CRC → ① 点选目标批注文字 → ② 框选多个独立云线回车，自动求最近点连线并建立匿名组。

XRA

导出校审记录汇总表

5列原生 AcDbTable

核心升级：自动按 MTEXT 优先检索并做 XData 去重，生成包含【序号、修订(△)、批注人、日期、问题及修改说明】的 5 列原生 CAD 表格。

操作方式：输入 XRA → 命令行提示检索到的有效批注总数，在图面上点击表格左上角插入点，瞬间成表。

ZKG

编组关联开关切换

PICKSTYLE 位运算

适用场景：默认生成的云线、引线与文字会自动成组。当需要单独拖动文字位置而不牵动云线时，可执行此命令临时解绑选择。

操作方式：输入 ZKG（或按 Ctrl+Shift+A）即可一键切换成组联动状态。

EDRC

修改已标注云线批注与三角编号

别名: XED

彻底解决编组修改痛点：传统 CAD 中若开启编组选择，改文字往往牵一发而动全身；文字一旦改长，托底基线又断截悬空。使用 EDRC 可穿透匿名编组，直达批注图元！

四维联动刷新：修改后自动同步刷新批注 MTEXT、更新云线与文字的 XData 扩展数据、重绘修订三角正多边形 (△) 与编号文本，并依据文字最新长度动态重算并拉伸/收缩托底基线端点，保持整个编组的物理与逻辑完整性。

GRC 文字批量刷外框云线 支持批量选择单行文字（TEXT）、多行文字（MTEXT）或属性定义（ATTDEF），自动提取外包围盒并向外偏移生成矩形修订云线外框。

XRA 全图校审汇总表导出 扫描全图带有 XDYX_SYS 扩展数据的批注对象，自动去重后在指定位置生成包含【序号、修订(△)、批注人、日期、问题及修改说明】的 5 列原生 AcDbTable 汇总表。
EDRC / XED 修改编组批注与编号 点击图中任意已标注云线、文字或三角符号，自动穿透编组提取所有关联图元，弹出专用面板修改批注词、批注人、日期及修订编号；修改后自动更新 MTEXT 内容、同步更新云线扩展数据 (XData)、刷新三角编号并依据最新文字长度自适应重算并拉伸/收缩托底基线，保持编组联动完好。
ZKG 编组关联选择开关 切换系统变量 PICKSTYLE 的第 1 位（Group selection）。开启时点击云线或文字将整体选中；关闭时可单独移动文字或微调引线端点。
SXDYX 重置系统默认配置 一键恢复修订云线的所有出厂参数（图层名、字高、默认弧长范围、笔触样式与内置词库），并清空当前注册表缓存。

AutoCAD 2007 – 2027 关键兼容处理机制

  • ✓ 规避 REVCLOUD 参数变更：AutoCAD 2021+ 对 REVCLOUD 命令新增了“对象(O)/矩形(R)/多边形(P)”子选项调整，v0.1 改用纯数学细分算法直接通过 entmakex 构建 LWPOLYLINE，彻底消除命令行交互差异。
  • ✓ 规避 GROUP 模态弹窗：在 AutoCAD 2007–2011 中调用 _.GROUP 会强制弹出“对象编组”模态窗口阻塞程序。v0.1 直接向 (namedobjdict) 的 ACAD_GROUP 词典写入匿名 AcDbGroup 记录（DXF 70=1）。
  • ✓ 注释性缩放版本检测：AutoCAD 2007（ACADVER = 17.0）尚无注释性功能。系统自动判断 (>= (atof (getvar "ACADVER")) 17.1) 后再挂载 AcadAnnotative 扩展数据并补偿 CANNOSCALEVALUE 比例。
  • ✓ 中文字体自动降级链路：创建 XDYX_Style 样式时，依次检测系统字体库中的 微软雅黑 (msyh.ttc/ttf) → 黑体 (simhei.ttf) → 宋体 (simsun.ttc) → txt.shx + gbcbig.shx，杜绝问号乱码。
